## 为什么做这个仓库

想考公的人，缺的从来不是「资料」。

搜一下就知道：铺天盖地的资源包、压缩包、"永久有效"的网盘链接、几十个 G 的课程录屏。它们有两个共同点——**来源都不可考**，而且**全都随时会失效**。

真正稀缺的东西反而是那些最难被搜到的：**官方入口在哪、什么时候开、哪份文件才是权威标准**。

这个仓库就做一件事：把散在 **180 多个政务网站**里的官方入口收进一张表，把时间线算准，把免费且权威的资源列清。

## 一、三个反常识的结论

### 1. 官方从不公开成套真题

国考试卷在考后由**机要渠道统一回收**，官方不发布真题与标准答案。你在网上见到的所有「历年真题 PDF」「14 年 64 套打包」，包括各类付费课里讲的真题，全部来自**考后考生回忆 + 教研机构交叉还原**。

这不代表不能用——优质还原版的准确度已经相当高，它依然是最主要的题源。但它意味着：**挑真题的第一标准是「来源」，不是「数量」**。

### 2. 官方真正免费且权威的，是这四样

**考试大纲 · 招考简章（职位表）· 报考指南 · 政策法规原文**

这四样只在官方专题网站发布，全部免费、可下载、可长期保存。多数人备考低效不是因为资料不够，而是从没打开过考试大纲——考什么、不考什么、各模块题型与分值，全在里面写着。

### 3. 国考已经没有「唯一官网」了

国家公务员局官网（`scs.gov.cn`）**已于 2025 年 8 月底下线**，公务员工作信息转由中央组织部相关网站发布；但**招考业务不受影响**——公告、职位表、报名、缴费、准考证、成绩查询，全部继续在「**中央机关及其直属机构考试录用公务员专题网站**」完成。

别再按老收藏夹里的 `scs.gov.cn` 点了。

## 三、2027 国考时间线（按历年规律推算）

国考节奏是公考里最稳的，近十年公告日几乎锁定 **10 月 14 日**，报名窗口固定 **10 天**。

| 环节 | 2027 年度（预计） | 2026 年度（实际，可对照） |
| --- | --- | --- |
| 公告 + 职位表 | 2026-10-14 | 2025-10-14 |
| 网上报名 | 2026-10-15 08:00 — 10-24 18:00 | 2025-10-15 — 10-24 |
| 资格审查截止 | 2026-10-26 18:00 | 2025-10-26 |
| 报名确认及缴费 | 2026-11-01 — 11-06 | 2025-11-01 — 11-06 |
| 准考证打印 | 笔试前一周（11 月下旬） | 2025-11 下旬 |
| 公共科目笔试 | 2026-11-28 — 11-29 | 2025-11-29 — 11-30 |
| 成绩与合格线 | 2027-01 中旬 | 2026-01-15 |
| 调剂 / 补录 | 2027-01 / 2027-05 | 2026-01 / 2026-05 |

> 报名只有 10 天，**不要卡最后两天**——审核不通过需要时间改报，最后一天提交等于放弃改报机会。

**参考规模**：2026 年度国考招录 **38119 人 / 20714 个职位**，过审人数超 **371.8 万**，税务系统约占招录总量六成。

## 四、考什么：国考行测结构

2026 年度起行测增加「政治理论」模块：

| 模块 | 副省级 | 市地级 / 行政执法类 |
| --- | --- | --- |
| 政治理论 | 20 | 20 |
| 常识判断 | 15 | 15 |
| 言语理解与表达 | 30 | 30 |
| 数量关系 | 15 | 10 |
| 判断推理 | 35 | 35 |
| 资料分析 | 20 | 20 |
| **合计** | **135 题** | **130 题** |

申论自 2022 年度起分三类卷：**副省级 / 市地级 / 行政执法类**。核心差异在材料与情境——**行政执法类不考大作文**，第五题为大型应用文。

## 六、免费的权威 / 公开资源清单

按「越靠前越权威」排序：

| 层级 | 资源 | 说明 |
| --- | --- | --- |
| 官方 | **考试大纲** | 专题站发布，**最高优先级**，决定复习范围边界 |
| 官方 | **招考简章（职位表）** | 专题站「相关下载」，选岗唯一依据 |
| 官方 | **报考指南** | 看清应届生身份、基层经历、专业目录认定口径 |
| 官方 | **政策法规原文** | 公务员法、录用规定、体检标准、违纪违规处理办法 |
| 官方 | 各省组织工作网 / 党建网 | 公告首发平台，比第三方转载快 1—2 天 |
| 出版 | 省级考试机构组织编写的真题汇编 | 权威性高、答案准确，官方渠道出版发行 |
| 平台 | 主流机构免费开放部分 | 在线题库基础功能、免费公开课、考后真题还原 |
| 公共 | 时政学习平台 | 申论与政治理论的素材积累 |

**一个判断标准**：如果一个「资料包」必须存进网盘才能用、链接还会定期失效，它既不是你的核心资产，也不值得占你的注意力。**真正该占位置的，是那四份官方文件。**

## 八、避坑清单

| ❌ | 说明 |
| --- | --- |
| 收藏 `scs.gov.cn` 当报名入口 | 该站已下线，招考走专题站 `bm.scs.gov.cn` |
| 去找"官方真题 PDF" | 官方不发，不存在 |
| 报名卡最后一天 | 审核不通过就没有改报时间 |
| 不看大纲就买课 | 大纲免费，且比任何导学课都准 |
| 专业名称按习惯写法填 | 必须与毕业证表述**完全一致** |
| 相信"永久有效"的网盘链接 | 政务信息以官网为准，二次转发的必然失效 |
